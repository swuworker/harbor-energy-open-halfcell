# Source attribution

This task adapts the negative-half-cell Darcy, transport, reaction and charge-balance model of RFBniCS: An open-source simulation framework for redox flow batteries, arXiv:2610.01840v1 (first public 2026-10-01).

Source repository: https://github.com/Ah-Aghabarari/RFBniCS

Pinned source commit: 8ad0b6414be39bea0b39dcb08b44abfcdff91b27.

The task is a new finite-domain numerical interface. Its nonuniform inlet boundary datum extends the upstream uniform inlet example. It does not reproduce the complete upstream software, its finite-element discretization, or a full battery. The source MIT permission notice is retained in LICENSE.txt. No code from upstream comparison directories is included.
